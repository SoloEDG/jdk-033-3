## 双标身份识别练习

海图下方提供“白屿岸嘴前的同色双标”训练：

- 船首方位与横倾会改变船上视野，前帆影会在固定时段遮挡双标。
- 可引用历史碎片；只有视线/视角可复核，并且共有一致的岸上参照时，碎片链才判定为可合并。
- 作答前若仍有两种身份解释通过全部可见证据，即使选中真标也会记录为“当时不可辨”，不得分。
- 作答结论会冻结证据截止时间；“回看首次露出”只把回放定位到排除其中一种解释的帧，不会改写原评分。

核心纯逻辑位于 `src/features/recognition/lib/identity.ts`，可在不挂载 Vue 组件的情况下复用或测试。
